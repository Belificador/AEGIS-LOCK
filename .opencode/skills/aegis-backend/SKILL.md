# SKILL: Backend - API de Seguridad, WebSockets & Middleware Seguro

## CONTEXTO DEL MÓDULO
Estás desarrollando el Backend asíncrono en Python (FastAPI) para el Sistema de Monitoreo de Seguridad y Gemelo Digital.
Esta API actúa como el núcleo central: recibe telemetría JSON de emisores externos (Simuladores, sensores IoT), aplica el motor de reglas de alerta, gestiona la autenticación JWT, interactúa con la IA local y persiste todo de forma blindada en Supabase (PostgreSQL).
